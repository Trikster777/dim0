# Dim0

Локальный интерфейс для работы с ИИ-моделями: веб-интерфейс поверх собственного бэкенда.
Форк, в который новые модули добавляются сбоку, не трогая ядро агента, чата и холста.

## Язык

**Модуль TTS**:
Необязательная часть Dim0, которая синтезирует речь локально, в контейнере на той же машине.
_Избегать_: плагин, фича, расширение

**Озвучка**:
Чтение ответа агента вслух синтетическим голосом — по нажатию кнопки у сообщения.
_Избегать_: озвучивание, голосовая подача, озвучка сообщения

**Голос**:
Спикер модели синтеза, которым читается ответ; выбирается в интерфейсе или берётся из переменной окружения.
_Избегать_: спикер, диктор, тембр, голосовая модель

**Список голосов**:
Набор голосов, который умеет текущая модель; приходит в интерфейс с бэкенда, а не зашит во фронтенд.
_Избегать_: поддерживаемые голоса, голоса по умолчанию, список моделей

**Автоозвучка**:
Автоматическое озвучивание каждого нового ответа агента без нажатия кнопки; по умолчанию выключена.
_Избегать_: автоплей, автоматическое воспроизведение, озвучка по умолчанию

**Ответ агента**:
Сообщение агента в ленте чата; его текст копирует «Скопировать» и озвучивает кнопка «Озвучить».
_Избегать_: ответ модели, ассистентский ответ, сообщение бота, реплика

**Модуль выключен**:
Состояние модуля TTS, когда он выключен: кнопка остаётся видимой и объясняет, что озвучка выключена.
_Избегать_: модуль недоступен, сломанная кнопка, ошибка 503

**Чанк**:
Часть текста ответа, которая синтезируется отдельным запросом к сервису; не длиннее 250 символов и режется только по границам предложений.
_Избегать_: фрагмент, кусок текста, сегмент, блок

**Подготовка текста**:
Обработка текста ответа на бэкенде перед отправкой в сервис: сначала латиница переводится в кириллицу, затем экранируются спецсимволы.
_Избегать_: нормализация, очистка текста, санитизация, препроцессинг

**CDATA-маркер**:
Обёртка вокруг каждого из символов `&`, `<`, `>`, которая делает текст валидным XML для сервиса синтеза.
_Избегать_: XML-экранирование, HTML-энтити, сущности, экранирование текста

**Склейка**:
Сборка кусков синтеза в один WAV-файл на бэкенде: заголовок берётся от первого куска, данные идут подряд.
_Избегать_: конкатенация, склейка на клиенте, сборка на фронте
