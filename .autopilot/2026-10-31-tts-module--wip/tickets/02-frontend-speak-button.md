## Что должно заработать

У каждого ответа агента в ленте — не у сообщений пользователя, и у **каждого** такого
сообщения, а не только у последнего — появляется кнопка «Озвучить». Клик: ответ читается
по-русски, голосом, который выбрал пользователь. Текст для озвучки — ровно тот, что копирует
«Скопировать».

Рядом с кнопкой — выпадающий список голосов и чекбокс «Автоозвучивать ответы агента».
Список голосов **приходит с сервиса** (через `GET /tts/voices` нашего бэкенда) и грузится
лениво — только когда пользователь его раскрыл. Выбранный голос и состояние автоозвучки
помнятся в браузере.

Модуль выключен — не поломка: кнопка остаётся видимой, один раз показывается понятный тост,
дальше кнопка неактивна и ничего не спрашивает.

## Критерии приёмки

- [ ] У ответа агента есть кнопка озвучки; у сообщения пользователя — **нет**. Кнопка есть у
      **каждого** сообщения агента в ленте, а не только у последнего.
- [ ] Клик озвучивает текст **того же** ответа, что копирует «Скопировать» (один и тот же
      источник текста).
- [ ] Четыре состояния кнопки: покой / идёт синтез / играет / ошибка. В «играет» — иконка
      остановки, клик по ней останавливает звук. В «ошибка» — короткая локализованная подсказка.
- [ ] Модуль выключен (503): кнопка **видима**, один тост с `t('tts.disabled')`, дальше кнопка
      неактивна с подсказкой `t('tts.disabled')` и **не отправляет** запросов до перезагрузки
      страницы.
- [ ] Пустой ответ агента: кнопка неактивна, запрос не отправляется.
- [ ] Бинарный ответ превращается в `Blob` и играется через `new Audio(URL.createObjectURL(blob))`.
      Звук не искажается (файл не проходит через `res.text()`).
- [ ] Отмена: клик «стоп» и новое сообщение пользователя прерывают запрос через
      `AbortController`, звук останавливается, `URL.revokeObjectURL` вызывается — ни звука,
      ни висящего запроса не остаётся.
- [ ] Список голосов приходит с бэкенда (`GET /tts/voices`), а **не зашит** во фронт: во
      фронте нет ни одной строки с именем голоса. Запрос уходит при **первом раскрытии**
      списка, а не при монтировании сообщения; дальше — из кэша, повторных запросов нет.
- [ ] Список голосов недоступен (503) — фронт не ломается: один локализованный тост, список
      скрыт.
- [ ] Выбранный голос сохраняется в `localStorage` под ключом `dim0.tts.voice` и переживает
      перезагрузку страницы — по образцу `dim0.lang`. Пока голос не выбран, он **не**
      отправляется, и бэкенд берёт голос по умолчанию.
- [ ] Чекбокс «Автоозвучивать ответы агента» есть, по умолчанию **выключен**, состояние — в
      `localStorage` под ключом `dim0.tts.autoSpeak`. Голос сам по себе не начинает звучать.
- [ ] Выбранный голос доезжает до бэкенда: `POST /tts` уходит с выбранным голосом.
- [ ] Ошибки локализуются **на фронте, по коду ответа**: 400 → `tts.empty`, 413 →
      `tts.too_long`, 502 → `tts.unavailable`, 503 → `tts.disabled`. Код ответа не теряется
      (в ошибке есть `status` и `endpoint`). Сырой английский `detail` бэкенда в интерфейс
      не попадает.
- [ ] Одиннадцать ключей `tts.*` есть и в `en.json`, и в `ru.json`: `play`, `stop`, `loading`,
      `error`, `disabled`, `too_long`, `unavailable`, `empty`, `voice`, `voicesUnavailable`,
      `autoSpeak` (подпись чекбокса автоозвучки, R53.4; список расширен с «десяти» по D06 —
      спека R74 поправлена). Имён голосов в словарях нет.
- [ ] Иконка динамика доступна как компонент из общего реестра иконок (в реестре и в
      реэкспорте), а не живёт только внутри выпадающего списка тем.
- [ ] `apiFetch` и карта ошибок изменены **только аддитивно**: бинарный ответ запрашивается
      отдельным вызовом с `Blob`, а в ошибке появились `status` и `endpoint`. Существующее
      поведение `apiFetch` и существующие записи карты ошибок не сломаны.
- [ ] Новых зависимостей нет: `webui/package.json` не изменён. Никаких Web Audio API —
      нативный `fetch` и `Audio`.
- [ ] `npm run check-all` зелёный.
- [ ] `npm run i18n:check` зелёный.
- [ ] `npx vitest run` зелёный, число тестов **не меньше** базовых 169 файлов / 1722 теста.
      Для нового компонента есть свои тесты (vitest): озвучка по клику, отмена, 503 → тост,
      ленивая загрузка списка голосов, чекбокс автоозвучки.
- [ ] `npx playwright test e2e/i18n-ru.spec.ts` зелёный.
- [ ] Существующие компоненты и роутеры не переписаны — новый компонент **добавлен** рядом.
