## Известные баги

- При автоозвучке кнопка показывает «играет» у самого старого ответа, а не у нового.
- При обрыве сети подпись кнопки показывает английское «Failed to fetch».
- Один очень длинный ответ → до 2 600 последовательных синтезов по 15 с; общего потолка нет — так решил владелец.
- При 503 во время автоозвучки играющее аудио не прерывается.
- `webui/docker-entrypoint.sh` на Windows получает CRLF (`core.autocrlf=true`) → контейнер `webui` не стартует: `/bin/sh: 1: /docker-entrypoint.sh: not found`. Не из этой ветки.
- Playwright на Windows не поднимает свой dev-сервер: `webui/playwright.config.ts` запускает `APP_PORT=4321 npm run dev` в POSIX-форме, `cmd.exe` её не исполняет → e2e молча берёт уже висящий сервер на 4321.
- `container_name: silero-tts` в compose фиксирован — конфликтует с любым другим контейнером с тем же именем.
- `backend/uv.lock` закрепляет `topix 0.3.94`, а `VERSION` говорит `0.3.101`; обычный `uv sync` переписывает lock — гонять тесты через `backend/.venv/Scripts/python.exe -m pytest`.
- Дробные числа в счётчиках i18next печатает с точкой (`1.5`), не с запятой.
- CRLF-тест `src/features/applet/compile/skill-examples.test.ts` починен: разбор блоков кода нормализует `\r\n` → `\n`.
