# Что пришло с прошлой сборки

Прошлый прогон: `.autopilot/2026-10-30-dim0-i18n-ru/` — русская локализация `webui/`, PR #1 смержен в `main` форка Trikster777/dim0.

## Договорились — не пересматривать

- Бэкенд Python и системные промпты LLM не переводим: правка = конфликты при Sync fork (R34, R32).
- Переключатель языка — в футере сайдбара рядом с темой, без новых панелей; ключ `localStorage.dim0.lang` (G10, G12).
- В `.tsx` меняются только строковые литералы на `t()`; разметка, пропсы и логика не трогаются (G01, R31).
- Тесты форсируют английский через `storageState` и `I18N_FORCE_LANG`; селекторы не переписываем (G13–G17).
- ESLint-плагин i18next не включаем, husky не добавляем; полнота — через `npm run i18n:check` (G18–G22).
- `@canvas-harness/*` и `src-tauri` остаются английскими; dev-экран `capture-spike` не переводим (G29–G31).
- Русские формы CLDR: `_one/_few/_many/_other`; `en.json` тоже содержит все четыре ради строгого паритета.
- Глоссарий и правила — в `I18N.md`, раздел 6.

## Известные баги

- CRLF-тест `src/features/applet/compile/skill-examples.test.ts` починен: разбор блоков кода нормализует `\r\n` → `\n`, на Windows тест зелёный (раньше примеры не компилировались вовсе — `it.each` получал пустой массив).
- Дробные числа в счётчиках i18next печатает с точкой (`1.5`), не с запятой: запятая потребовала бы `Intl.NumberFormat` в местах, которых правка не касалась.
- В брифе было «74 серверных сообщения», фактическая инвентаризация — 67 уникальных строк (85 вхождений); все в `I18N.md`, раздел 7.1.
